# 자동차 경주 게임 - 구현 기능 목록

## 1️⃣ 입력 처리 기능
- [ ] 사용자로부터 **경주할 자동차 이름들**과 **시도할 횟수**를 입력받는다.
- [ ] 자동차 이름은 **쉼표(,)** 기준으로 구분한다.
- [ ] 자동차 이름은 **5자 이하**여야 하며, 초과 시 `IllegalArgumentException`을 발생시킨다.
- [ ] **빈 문자열** 또는 **잘못된 구분자 입력** 시 예외를 발생시킨다.
- [ ] **중복된 이름**이 존재할 경우 예외를 발생시킨다.
- [ ] 시도할 횟수가 **0 이하이거나 숫자가 아닐 경우** 예외를 발생시킨다.

## 2️⃣ 자동차 객체 생성 및 상태 관리
- [ ] 입력받은 이름으로 자동차 객체를 생성한다.
- [ ] 각 자동차는 **현재 이동 거리(진행 상태)** 를 저장한다.
- [ ] 자동차의 이동 상태는 `Map<String, Car>` 또는 자동차 리스트로 관리한다.

## 3️⃣ 전진 조건 및 이동 로직
- [ ] `Randoms.pickNumberInRange(0, 9)`를 사용하여 0~9 사이의 랜덤값을 구한다.
- [ ] **4 이상일 경우 전진**, 미만일 경우 정지한다.
- [ ] 입력된 횟수만큼 반복하여 각 턴마다 자동차의 이동을 처리한다.
- [ ] 이동 로직은 `Car` 클래스 내부의 `move()` 메서드로 캡슐화한다.

## 4️⃣ 실행 결과 출력
- [ ] 매 시도(turn)마다 모든 자동차의 이동 결과를 출력한다.  
- [ ] 모든 시도 완료 후 **최종 우승자(들)** 을 출력한다.
- 우승자가 여러 명일 경우 쉼표(,)로 구분한다.
- 예시: `최종 우승자 : pobi, jun`

## 5️⃣ 코드 규칙 및 품질
- [ ] **들여쓰기(depth)** 는 최대 2단계까지만 허용한다.
- [ ] **삼항 연산자**를 사용하지 않는다.
- [ ] 메서드는 **하나의 역할만 수행**하도록 최대한 작게 분리한다.
- [ ] **Java Code Convention**을 준수한다.

## 6️⃣ 테스트 코드 (JUnit5 + AssertJ)
- [ ] 정상 입력 시 자동차가 올바르게 생성되는지 테스트
- [ ] 랜덤값 4 이상일 때만 전진하는지 테스트
- [ ] 입력값이 비어있거나 잘못된 경우 예외 발생 테스트
- [ ] 시도 횟수만큼 반복 실행되는지 테스트
- [ ] 우승자 판별 로직 테스트 (단독/공동 우승)

# 🧾 Commit Convention (AngularJS Style)

| Type | Description |
|------|--------------|
| **feat** | 새로운 기능 추가 |
| **fix** | 버그 수정 |
| **docs** | 문서 수정 (README 등) |
| **style** | 코드 포맷 변경 (세미콜론, 공백 등 — 기능 영향 없음) |
| **refactor** | 코드 리팩토링 (기능 변경 없이 구조 개선) |
| **test** | 테스트 코드 추가 또는 수정 |
| **chore** | 빌드, 설정, 기타 유지보수 작업 |
